# WoS Rally Coordinator

URL: https://aoaowos.github.io/wos-rally-coordinator/

Whiteout Survival の連続集結タイミングを管理するためのHTMLツールです。

## 機能

- 現在のUTC時刻をリアルタイム表示
- 参加プレイヤーごとの行軍秒数を入力
- 最長行軍のプレイヤーを基準に、各プレイヤーが何秒で集結を開始するかを計算
- 集結到達時間指定モードで、ゲーム内の到達指定時刻を計算
- 1分、3分、5分、10分の集結時間に対応
- 余裕時間秒数を追加可能
- 到達指定秒をx0秒または00秒へ切り上げ可能
- 入力内容と最後の計算結果をブラウザに保存

## 使い方

1. 連続集結に参加するプレイヤーにチェックを入れます。
2. プレイヤー名と行軍秒数を入力します。
3. 集結分数、余裕時間、到達指定秒の調整方法を設定します。
4. 「計算する」を押します。
5. カウントダウンモードと集結到達時間指定モードの結果を確認します。
